# Glossário

Vocabulário controlado usado neste repositório. Mantê-lo atualizado garante consistência entre todas as UCs.

| Termo | Definição |
|---|---|
| **UC** | Unidade Curricular — uma disciplina do curso |
| **PI** | Projeto Integrador — projeto que conecta conhecimentos de várias UCs |
| **Atividade** | Entrega pontual de uma UC (trabalho, exercício, estudo de caso) |
| **Classificação** | Agrupamento de conteúdos em categorias com base em um critério (tipo, etapa, disciplina) |
| **Taxonomia** | Sistema de nomenclatura e vocabulário controlado usado para nomear pastas/arquivos |
| **Metadados** | Dados que descrevem outro dado (ex: data, autor, status, tags de uma atividade) |
| **Navegação** | Caminhos e links que permitem ao usuário se mover pela estrutura |
| **Encontrabilidade** | Facilidade de localizar um conteúdo específico (via busca, nomenclatura ou índice) |
| **Relações entre conteúdos** | Conexões explícitas entre atividades de UCs diferentes ou entre UC e PI |
